# 라벨링 가이드 — 속성별 감성(ABSA)

리뷰 1건마다 아래 **8개 속성** 각각에 4개 클래스 중 하나를 부여한다.

| 값 | 클래스 | 기준 |
|---|---|---|
| 0 | 미언급 | 해당 속성에 대한 언급이 없음 |
| 1 | 긍정 | 해당 속성을 칭찬·만족 |
| 2 | 보통 | 중립적 언급, 또는 장단점이 함께 있음("스토리는 좋은데 후반이 아쉽다") |
| 3 | 부정 | 해당 속성을 비판·불만 |

## 속성 정의

| # | 속성 (컬럼명) | 포함 | 제외 / 경계 |
|---|---|---|---|
| 1 | 그래픽 (`graphics`) | 그래픽, 화질, 아트 스타일, 풍경, 비주얼, 캐릭터 외형, 시각 연출 | 프레임·사양 → 최적화 |
| 2 | 최적화 (`performance`) | 프레임(FPS), 프레임 드랍, 렉·끊김, 로딩 시간, 요구 사양, 발적화, 핑·지연 | 접속 불가·튕김 → 운영 |
| 3 | 스토리 (`story`) | 줄거리, 서사, 캐릭터·동료, 대사, 퀘스트 내용, 세계관, 엔딩 | |
| 4 | 게임성 (`gameplay`) | 재미·중독성·몰입, 전투·시스템, 콘텐츠 양·반복성, 난이도, 밸런스, 자유도, 멀티·협동 재미 | "갓겜/추천/인생겜"처럼 **근거 없는 총평만** 있으면 미언급 |
| 5 | 조작감 (`controls`) | 조작, 키 배치, 패드 지원, 타격감, 카메라, UI·인터페이스, 움직임 반응성 | |
| 6 | 사운드 (`sound`) | BGM·OST, 효과음, 성우·더빙, 음향 | |
| 7 | 가격 (`price`) | 가격, 가성비, 할인, DLC 가격, 과금·현질·유료 아이템, 무료 여부 | |
| 8 | 운영 (`operation`) | 버그, 튕김·크래시, 서버 불안정·접속 불가, 핵·치터, 개발사·패치·업데이트 정책, 운영 대응, 한글화(번역) 품질 | |

## 판정 원칙

1. **명시적 근거가 있을 때만** 부여한다. 리뷰 전체가 추천(👍)이라는 이유만으로 속성을 긍정 처리하지 않는다.
2. 반어·비꼼은 실제 의미로 판단한다("최적화 진짜 '훌륭'하네요 30프레임" → 최적화 부정).
3. 은어 해석: 갓겜(총평), 발적화(최적화 부정), 똥겜(총평 부정), 노가다(게임성 — 반복 비판이면 부정), 현질/과금(가격), 핵(운영).
4. 과거 상태와 현재 상태가 다르면 **현재(리뷰 작성 시점) 평가**를 따른다("출시 땐 버그 투성이였는데 지금은 괜찮다" → 운영 긍정 또는 보통).
5. 한 속성에 긍정·부정이 섞이면 보통(2), 한쪽이 확실히 우세하면 그쪽으로.
6. 리뷰가 길면 모델 입력 길이에 맞춰 **앞부분(약 500자)** 기준으로 판정한다.
7. **은유·간접 표현** (검수 시도 중 정리한 규칙 — 기존 LLM 라벨에는 반영되지 않았으며 향후 재라벨링 시 적용)
   - 게임 속 **구체적인 행동·시스템**을 즐겼다/싫었다는 은유는 해당 속성으로 판정한다.
     예: "소매치기만 하고 다니다 보니, 현실에서도 하고 싶어요.." → 게임성 긍정 (소매치기 시스템이 재밌다는 뜻)
   - 근거 없는 **총평**("인생겜", "시간 순삭", "갓겜")은 속성 미언급으로 두고, 리뷰 전체의 호불호는 **종합 평가**가 담당한다.

## 종합 평가 (overall)

- 속성 8개와 별도로 리뷰 전체의 **추천/비추천**을 예측한다.
- 정답은 리뷰 작성자가 직접 누른 추천 버튼(`voted_up`)이므로 **추가 라벨링·검수가 필요 없다**.
- 속성이 모두 미언급인 총평형·은유형 리뷰도 종합 평가로 호불호를 표시할 수 있다.
- 한계: "추천은 하지만 운영은 최악"처럼 버튼과 본문 어조가 다른 리뷰가 있어 약지도(weak label)로 취급한다.

## 라벨링 절차

- 1차 라벨: Claude (Claude Code, `claude-opus-5-5`)가 위 가이드에 따라 2,000건을 100건 단위로 라벨링
- 검수: 테스트셋을 사람이 검수해 보았으나(약 150건 정독, 이후는 훑어봄) 은유·장단점 혼합·운영/게임성 경계 등에서 **검수자 기준이 일정하지 않아** 최종 평가에는 쓰지 않음
  - 최종 평가는 학습 데이터와 같은 기준인 **LLM 라벨**로 통일 (학습·평가 기준 일관성)
  - 검수 결과(라벨이 바뀐 리뷰 20건)는 LLM 라벨 품질을 가늠하는 참고 자료로만 보고
- 학습·검증 데이터는 LLM 라벨을 그대로 사용(약지도, weak supervision)
